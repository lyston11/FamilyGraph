## 验证方式

文档校验：有效链接、完整 MR/E-O/E-AC 映射、真实出处、不存在用占位字段推断能力的表述。
合成复现：使用实际服务路径/真实迁移临时库、fake transport 和冻结时钟；不连接开发/线上主库，不外发私有资料。
能力比较：同数据集、同版本、同来源权限和基准成本口径；离线模拟不证明真实模型生成质量。
若只调整文档，无需再跑全项目业务测试；如果后续新增评估代码，只运行实际相关检查，并在记录中给出命令/版本/结果。
