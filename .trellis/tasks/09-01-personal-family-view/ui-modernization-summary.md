# 家族树视图 UI 现代化总结

## 实施日期
2026-09-02

## 优化目标
将 09-01-personal-family-view-frontend 的前端设计从传统样式升级为现代化、流畅、高品质的视觉体验。

## 核心改进

### 1. **成员卡片（MemberNode.vue）**

#### 视觉深度与层次
- **玻璃态毛玻璃效果**：卡片背景使用 `backdrop-filter: blur(12px)`，营造半透明悬浮感
- **多层阴影系统**：
  - 主阴影：`0 4px 16px` 提供深度
  - 光晕边框：`0 0 0 1px` 主色光晕
  - 顶部高光：`inset 0 1px 0` 白色内发光
- **渐变背景**：135° 对角线渐变，从主色到淡化，增强立体感
- **悬停微交互**：
  - `scale(1.03)` 轻微放大
  - 阴影扩大至 `0 8px 24px`
  - 边框光晕增强至 15%

#### 字体与排版
- **流式字号**：使用 `clamp()` 实现响应式字体
  - 卡片标题：`clamp(15px, 1.2vw, 17px)`
  - 称谓标签：`clamp(12px, 1vw, 13px)`
- **改进字重对比**：标题 700，正文 500-600
- **优化行高**：正文 1.7，标题 1.4

#### 组件细节
- **头像圆角**：从固定圆角改为 `999px` 完整圆形（modern 主题）
- **称谓标签**：
  - 渐变背景（90° 横向，8%→4% 主色）
  - 彩色边框（20% 主色混合）
  - 悬停时边框加粗、背景加深
- **可见性徽章**：
  - Icon + 文字双重表达（符合无障碍）
  - 悬停动画：icon 放大 1.15×、文字轻微位移
- **"自己"标记**：
  - 双层边框（实线 + 光晕）
  - 渐变文字（主色→墨色）

#### 状态表达
- **lineage_summary 虚线卡**：虚线边框 + 族谱 icon
- **self_private 锁定卡**：锁形 icon
- **household_detail 家庭卡**：无额外 icon（默认状态）

## 设计原则

### 视觉语言
1. **玻璃态美学**：毛玻璃 + 半透明 + 光晕边框
2. **多层深度**：阴影 + 边框 + 内高光三层立体感
3. **流畅动效**：弹性缓动（cubic-bezier(0.34, 1.56, 0.64, 1)）
4. **渐变丰富**：对角线渐变（135°）贯穿始终

### 交互反馈
1. **悬停微交互**：scale、translate、阴影变化
2. **进入动画**：淡入、滑入、缩放（0.5-0.6s）
3. **按下反馈**：`scale(0.95)` 缩小

### 无障碍设计
1. **不只靠颜色**：icon + 文字双重表达
2. **足够对比度**：主色与背景 ≥4.5:1
3. **动效降级**：`prefers-reduced-motion: reduce` 时禁用所有动画
4. **语义化标记**：`role="button"`, `aria-hidden="true"`

### 响应式适配
1. **流式字号**：clamp() 保证可读性
2. **移动端优化**：
   - 工具栏单行横向滑动
   - 44px 最小点击目标
   - 更小内边距
3. **触控支持**：VueFlow 内置双指缩放/拖拽

## 技术细节

### CSS 特性
- `backdrop-filter: blur(12px)` + 降级方案
- `color-mix(in srgb, ...)` 动态颜色混合
- `-webkit-background-clip: text` 文字渐变
- `clamp()` 流式字号
- CSS Grid + Flexbox 混合布局
- CSS Custom Properties 全局 token 系统

### 动画性能
- 仅使用 `transform` 和 `opacity`（GPU 加速）
- 避免 `width`、`height`、`top`、`left` 动画
- 降级方案：`@media (prefers-reduced-motion: reduce)`

### 浏览器兼容
- `backdrop-filter` 降级：不支持时改用不透明背景
- `-webkit-` 前缀：Safari 兼容
- Flexbox/Grid：现代浏览器均支持

## 设计 token 使用

### 颜色
- `--fg-accent`: 主色（渐变、边框、高亮）
- `--fg-ink`: 墨色（正文、标题）
- `--fg-ink-secondary`: 次要文字
- `--fg-ink-faint`: 禁用/占位文字
- `--fg-surface-raised`: 抬高表面
- `--fg-surface-sunken`: 凹陷表面
- `--fg-line`: 分隔线
- `--fg-line-strong`: 强调边框

### 尺寸
- `--fg-radius-card`: 卡片圆角（基准）
- `--fg-radius-control`: 按钮/控件圆角
- `--fg-shadow-card`: 卡片阴影
- `--fg-shadow-raised`: 悬停阴影

### 字体
- `--fg-font-display`: 标题字体
- 流式字号：`clamp(min, fluid, max)`
