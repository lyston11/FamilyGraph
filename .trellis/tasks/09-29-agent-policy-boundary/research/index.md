# 策略边界研究索引

## 已确认

共享 guard 存在关键词硬阻断、安全替换文本可自触发、错误分类混淆和事后才判失败的机制。后端输入/工具参数也有关键词拒绝，须跨层同步。详见 [摘要](policy-boundary-summary.md)。

## 已否决的推断

同 input_hash 不同结果、部分出站 200 或合成复现，均不能证明 run 48 的实际触发原因或排除泄漏；不能以 assistant role 为可信豁免。

## 当前决定

规划采用既有服务端授权 + 按合同处理内容 + run 级硬阻断 + 安全诊断，不创建新策略平台。完整方案见任务 `design.md`。

## 未解决的技术项

SDK 中止/重试的实际机制和来源坐标复用由实施前门槛验证；历史事件缺失的正文与类型不可恢复，不列为必须重新采集的材料。
