# M3 附件、公农历完善、统计与搜索

> 权威上下文：[.trellis/HANDOFF.md](../../HANDOFF.md)。已确认决策视为锁定。

## Goal

补全 v1 功能面：图片/链接附件、公农历体验完善、统计页、全局搜索。出口标准：**功能全绿**——附件可传可见、农历含闰月往返正确、统计准确、搜索不越权。

## Background（锁定决策引用）

- U7：v1 范围包含搜索、统计（总人数/世代分布/男女比例）、图片/链接附件。
- D7：公/农双历，录入任一自动换算（lunar-python 含闰月），原文备注。
- U5/T 约束：搜索遵循可见性基线，过滤逻辑复用 M2 的 `visibility.py`。
- 非目标边界：定位附件仅预留字段；无 PDF/打印导出。

## Requirements

### 附件系统
```
attachments  id, user_id, type(image|link|location*), url_or_path,
             title, description, uploaded_by, created_at   (*location 仅枚举预留)
```
- 图片上传：类型白名单（jpg/png/webp/heic 转换可选）、单文件 ≤10MB、存数据卷 `/data/uploads`、文件名服务端生成（防路径穿越）。
- 档案页相册区：网格缩略图 + 点击放大 + 删除（删除需权限：本人或 D5 有编辑权者）。
- 链接附件：标题 + URL + 描述，展示为卡片列表。
- 头像复用图片存储（开放问题 #4 默认方案）。

### 公农历完善
- 录入交互优化：历别切换时已填日期自动换算填充另一历输入框；闰月显式标记 UI。
- 生卒年份参与列表长幼排序与世代角标计算（对 M1 规则的正式落地）。
- 边界处理：无法换算的模糊历史日期允许只存原文备注（original_text），另一历留空并提示。

### 统计页
- 总人数（可见范围内）、世代分布柱状图（按树骨架世代层级）、男女比例、近期生日列表（30 天内，公历口径）。
- 数据范围 = 当前用户可见性基线内的成员集合。

### 全局搜索
- 顶部搜索框：名字/称谓标签匹配，结果 = 可见性基线内成员摘要卡，点击进入详情（遮罩规则同 M2）。
- 空间内快速筛选：家庭空间页面内按称谓/名字即时过滤画布卡片。

## Acceptance Criteria

- [ ] 上传 jpg/png 各一张成功显示；上传 .exe 被拒；超 10MB 被拒；删除后文件从数据卷移除。
- [ ] 链接附件增删后档案页正确刷新。
- [ ] 农历"二〇二四年闰二月初三"录入 → 公历自动生成且再反向换算一致；纯原文备注模式可保存。
- [ ] 统计页数字与 fixture 完全一致（写对比测试）；不可见成员不计入。
- [ ] 搜索命中遮罩对象时详情仍为遮罩态；独立家族成员不出现在结果中（回归 M2 测试）。
- [ ] 生日提醒列表覆盖闰月生日（按当月有则列出的近似策略即可，实现说明写入代码注释）。

- PDF/图片导出、打印样式（v2）。
- Excel 导入（v2）。
