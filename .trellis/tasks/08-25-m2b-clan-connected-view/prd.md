# m2b 家族连通视图

> 父任务：[08-25-m2-clan-view-privacy](../08-25-m2-clan-view-privacy/prd.md)｜依赖：m2a

## Goal

"小家庭→大家族"的涌现视图：连通分量计算 + 树形大图 + 摘要卡交互。

## Requirements

- clan 定义：从我的任一 active 空间沿 active 关系边可达的成员集合；跨连通分量互不可见（U4）。
- 树形大图（d3-hierarchy + Vue Flow）：缩放/平移/分支折叠（默认展开深度 2 层——待定决策 Q5 默认方案）。
- 非同空间成员卡分两态：**直系结构边对端**渲染完整卡（QU1=B）；其余为摘要卡——必要字段（名字/称谓/世代）+ 归属者披露开关已开放的类别（AD-9，如公开的照片/生卒），未开放项 MaskedField 锁样式 + 「申请进入 TA 的家庭空间」入口（调 m2c join_request API，UI 先做按钮+提交反馈，审批列表在 m2c）。
- 家庭⇄家族切换按钮 + 视口缩放过渡（基础版动画，m4a 打磨）。
- 「家族空间公开范围」开关组 UI（AD-9）：档案编辑页内五类开关（avatar/photos/dates/bio/attachments），调 m1a 的 disclosure API；改动即时反映在摘要卡。

## Acceptance Criteria

- [ ] 三家庭 fixture（A—elder→B、B—peer→C、D 独立）：A 的家族视图含 B 完整卡与 C 摘要卡（披露默认关闭时锁样式），无 D 任何节点。
- [ ] C 开放 photos 披露后其摘要卡即时显示照片缩略；关闭后回到遮罩。
- [ ] 直系对端卡片不受披露开关影响（始终完整）。
- [ ] 三家庭 fixture 中 A 的家族视图含 B、C 的摘要节点，无 D 家族任何节点。
- [ ] 折叠某分支后子树隐藏且布局重排；展开深度记忆。
- [ ] 摘要卡点击只能看到遮罩态详情，申请按钮可用并提示已提交。
- [ ] 家庭/家族两视图切换状态正确保持，刷新后回到默认家庭视图。

## Non-goals

- 动画性能打磨与移动端手势（m4a）；join_request 审批流（m2c）。
