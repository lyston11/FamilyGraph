## Requirements

### 过渡体验
- 家庭空间 ⇄ 家族空间切换：视口缩放 + 淡入过渡动画（CSS/Vue transitions，60fps 目标）。
- 布局切换（画布/树状/列表）节点位置平滑过渡。
- 建档成功 → PIN 一次性展示弹窗的仪式感设计（大字号 PIN + 复制按钮 + "请截图保存"提醒）。
- 空状态引导：新用户首进家庭空间的空画布引导文案与"添加第一位家人"入口。

### 响应式
- 断点适配：列表/详情/表单页在 ≤768px 视口完整可用；底部导航或折叠菜单。
- 画布在移动端：双指缩放、单指平移、卡片点按放大详情；不要求编辑摆放。

### 管理员后台（极简）
- 入口仅 is_admin 用户可见。
- 功能三件：
  1. 用户搜索 → 重置 PIN（生成新随机 PIN 一次性展示）。
  2. 数据修正：改名/改归属模式/转移代管权（处理创建者失联等情况）。
  3. 删除档案的特权通道（同样二次确认 + 级联，审计日志记录操作者与时间）。
- 管理操作写 `admin_audit` 日志表。

### 部署交付
- `docker compose up --build` 全栈启动；数据卷持久化 SQLite + uploads；容器内固定 Node/Python 版本。
- README：本地启动、备份（单文件拷贝 SQLite + uploads）、迁云步骤清单（域名/DNS/HTTPS 用 Caddy 或 Nginx+certbot 二选一给出文档即可）。
- 删除档案的级联清理在 M1 已实现，此处补全端到端验证与确认弹窗文案。

## Acceptance Criteria

- [ ] 全新环境一条命令启动，完成 HANDOFF 第三节验收标准第 1 条。
- [ ] 手机视口（375px）走通：登录 → 浏览家庭空间三布局（只读交互可接受）→ 打开档案详情。
- [ ] 家庭⇄家族切换动画无卡顿掉帧（目测 60fps 或 DevTools 无长任务告警）。
- [ ] 管理员重置某用户 PIN 后，该用户以新 PIN 登录成功、旧 PIN 失效。
- [ ] 管理员删除档案触发二次确认，确认后关系边全部清除，audit 表有记录。
- [ ] README 按"备份 = 拷贝两个路径"能被不懂容器的人执行成功。
- [ ] 全量回归：M0-M3 的验收标准复跑通过。

## Non-goals

- HTTPS 证书自动化运维（文档说明即可）。
- 监控/告警/日志采集平台。
- 性能压测调优（几十人规模）。
- v2 所有条目（agent 推荐、定位、导出、跨家族精细策略等）。
