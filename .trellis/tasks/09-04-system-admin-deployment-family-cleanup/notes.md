# 子任务 4 决策与实现笔记

- 本任务只在子任务 1/2/3 之后执行：先有独立 admin listener 与后台前端，再谈部署隔离；否则清理家庭端会让后台无处可连。
- 家庭端清理的判定标准是“产物级”而非“源码级”：即使源码里没有后台组件，dist、source map、路由表或 OpenAPI 泄露后台字符串同样算失败。
- `/system-admin`、`/admin`、`/admin-api` 在家庭 web/API 上必须与随机未知路径行为一致（普通 404），不能用 403/重定向/自定义错误页——那本身就是存在性 oracle。
- 生产 admin web 绑定 `127.0.0.1:8081`，由 VPN/内网反代进入；8002 不发布宿主。家庭入口与后台入口不能通过同一公网反代理互通。
- `ADMIN_JWT_*` 与凭据文件只存在于 api 容器/数据卷；绝不作为 Docker build arg 或 Vite env 进入任何前端构建。
- 家庭端视觉改版（09-04-frontend-glass-cosmic-redesign）与本任务的清理范围可能同时触碰 `frontend/`：清理只删除后台痕迹文件/代码，不重排或回退视觉 WIP；如冲突无法避免，停止并等待并行任务先行合并。
- 回滚方向永远是“停用后台、保留家庭”，不允许出现家庭服务依赖后台组件的中间态。
