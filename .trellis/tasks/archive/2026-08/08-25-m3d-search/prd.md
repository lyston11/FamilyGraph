# m3d 搜索

> 父任务：[08-25-m3-media-lunar-stats-search](../08-25-m3-media-lunar-stats-search/prd.md)｜依赖：m2a（命中范围受授权约束）

## Goal

全局搜索产品化：顶部搜索框 + 结果呈现 + 空间内快速筛选。

## Requirements

- `GET /search?q=` ：名字/称谓标签匹配（LIKE 起步，几十人规模无需全文引擎）；结果=可见性基线内摘要卡，点击进遮罩态详情；invisible 成员永不返回。
- 家庭空间页内即时筛选：按名字/称谓过滤画布卡片（纯前端，作用于 store 数据）。
- 搜索防抖、空态与无权限命中的统一文案。

## Acceptance Criteria

- [ ] 名字与称谓均可命中并展示摘要卡；点击进入详情为遮罩态（矩阵回归）。
- [ ] D 独立家族成员在任何关键词下都不出现。
- [ ] 空间内筛选实时生效且清空恢复完整画布。

## Non-goals

- 拼音/模糊音检索；全文搜索引擎；跨字段高级查询（v2 再议）。
