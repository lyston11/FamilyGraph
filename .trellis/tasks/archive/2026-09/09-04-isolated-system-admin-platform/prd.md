# 独立系统管理员后台与全业务监控平台

## Goal

建立一个与家庭用户端完全分离的系统管理员平台。系统管理员使用独立后台端口、独立前端构建、独立 Admin API listener、独立 JWT 签发域和独立浏览器会话，按“空间管理员 → 其管理的家族空间 → 空间健康与治理状态”查看全业务运营信息。

家庭用户端不编译、不展示、不跳转、不注册任何系统管理员相关代码、路由、文案、身份字段或 API。系统管理员可以读取允许的业务数据，但不能读取认证秘密、私人正文或高敏感档案；所有读取留痕。后台首版除空间管理员申请审批外不提供业务写操作。

## User value

- 普通家庭用户只看到家庭产品，不知道后台入口、后台端口或系统管理员身份模型。
- 运维人员可以在受控网络进入专用后台，按空间管理员聚合监控其家族空间，并钻取到成员、档案、关系、运营和 Agent 健康数据。
- 后台读取权限、敏感字段访问、错误诊断和审批动作均可追责、可测试、可回滚。

## Confirmed decisions

1. 前后台采用独立前端项目和独立端口：家庭开发 `5173`、容器 `8080`；后台开发 `5174`、容器 `127.0.0.1:8081`。
2. 家庭 API listener `8000` 与 Admin API listener `8002` 完全分离；8002 由同一个后端容器内的独立 FastAPI app/listener 提供，生产不发布 8002 到宿主。
3. 家庭前端和后台前端使用不同 origin、不同存储命名空间、不同 token 会话；8002 使用独立 `ADMIN_JWT_SECRET`、issuer、audience。
4. 系统管理员使用用户名 + 强密码，不使用家庭用户的名字 + 六位 PIN；家庭用户认证协议保持不变。
5. 单一系统管理员账号：初始用户名为 `admin`，部署时自动生成随机强密码，写入数据卷权限 `0600` 的一次性凭据文件；首次登录强制改密；系统管理员可修改用户名和密码；不支持旧 system_admin PIN 账号迁移窗口。
6. 忘记密码只走受限运维恢复命令，不提供公网/家庭端忘记密码接口；MFA 延后另立任务。
7. 后台可读取全业务运营信息，但排除认证秘密、私人正文和高敏感档案。当前模型没有电话/邮箱/地址字段，本任务不新增这些档案字段。
8. 基础档案可见姓名、头像鉴权缩略图、生卒日期、性别、简介；精确住址、学校/单位、健康、未成年人敏感字段、私人描述、关系证据原文和附件原文永不返回。
9. 关系只读结构化关系边和已确认事实；运营可读通知、申请、交接、ActionCard 和统计状态；Agent 可读运行元数据和二次脱敏诊断，不读对话/上下文/工具结果正文。
10. 后台以管理员 → 空间为主视图，支持分页、搜索、筛选、关联钻取、五秒轮询监控和独立异常队列。
11. 普通列表/运营详情直接读取并审计；敏感详情先提交理由，取得绑定单个用户或空间、有效 30 分钟的访问会话；访问会话只在后台前端内存保存。
12. 首版纯只读，唯一业务写例外是空间管理员申请审批：approve 可直接提交，reject 必须填写理由；两者均二次确认、审计，终态不可改判。
13. 家庭端访问 `/system-admin`、`/admin`、`/admin-api` 等路径统一普通 404，不跳后台、不提示后台存在；家庭 bundle 不含后台模块图。
14. 系统管理员默认由部署启动自动生成，不提供公开首启页面；家庭注册另立任务。

## Background / current baseline

- 当前仓库是单一 Vue SPA：家庭路由和 system-admin 路由在同一个 router、同一个 bundle、同一个 `fg.refresh_token` localStorage key。
- 当前 Vite 只有一个 dev server 和 `/api → localhost:8000` 代理；Docker Compose 只有一个 web 容器映射 `8080:80`；Nginx 只有一个 server。
- 当前后端公开 `app` 同时挂载家庭路由与 `system_admin/admin_metadata` 路由；已有 `internal_app`/`serve.py` 的双 listener 模式可复用，但需要新增真正的 Admin API app。
- 当前 system_admin 认证代码仍使用独立主体 + PIN 字段；本任务将其改为管理员用户名/密码合同，不改家庭 `accounts.pin_hash`。
- 当前 `backend/app/api/admin.py` 含历史家庭 break-glass 路由，不能直接注册到 8002；应拆出安全只读/审批能力，旧模块最终移除。
- 当前 `User` 模型有姓名、性别、生卒、简介、头像路径等字段，但没有电话、邮箱、地址、学校/单位、健康字段；不得伪造这些字段的实现。
- 当前 `audit_log.actor_id` 指向家庭 `users`，不能作为独立系统管理员读取审计的唯一结构；需要独立访问会话/审计模型。

## Requirements

### SAP-F1：家庭端零后台知识

- 家庭构建产物、source map、路由表、OpenAPI 客户端和公开文案不得包含 system-admin 组件、管理员 API 路径、`system_admin`/`platform_operator` 后台身份枚举或后台端口。
- 家庭端只能提供家庭用户认证和家庭业务；访问后台相关路径返回普通 404，不透露资源存在性。
- 家庭端不能因为 family_user 会话而跳转到后台，也不能提供“切换管理员”按钮。

### SAP-F2：独立管理员平台

- 后台拥有独立 `system-admin-frontend/` 项目、独立构建、独立存储键和独立 `/admin-api` 客户端。
- 后台开发监听 `5174`，生产 web 默认只绑定宿主回环 `127.0.0.1:8081`，由 VPN/内网反代进入。
- 后端 8002 只挂载 Admin API app；8000 不注册管理员路由。

### SAP-F3：管理员认证与会话

- 系统管理员使用用户名 + 强密码；初始账号 `admin` 的随机密码写入 `0600` 一次性文件，首次改密后删除。
- 管理员可以修改用户名和密码；变更、锁定、运维恢复立即撤销全部管理员 access/refresh 会话。
- access token 短期有效，refresh token 轮换并有绝对有效期；JWT 使用管理员独立 secret/issuer/audience。
- 8002 只接受 system-admin 签发域；家庭 token 即使被复制到 8002 也拒绝。8000 只接受家庭签发域。
- 不实现固定 `admin/admin`、MFA、邮件找回或旧 PIN 兼容。

### SAP-F4：管理员监控读模型

- 后台首页以 active `space_admin` 为聚合根，展示其管理空间数量、健康状态和异常。
- 空间详情支持成员/档案、关系/已确认事实、治理积压、通知、统计、Agent/job 运行数据和审计时间线。
- 列表、搜索、状态/时间筛选必须分页并有上限；禁止一次性全库拉取和批量导出。
- 无 active 管理员、双管理员、管理员锁定/删除/关系异常的空间进入独立异常队列；系统只读展示，不自动修复。

### SAP-F5：数据分级与敏感访问

- 基础档案白名单：姓名、头像鉴权缩略图、生卒、性别、简介、状态和时间；附件仅安全元数据，不返回路径、描述正文或原文件。
- 关系白名单：结构化关系边、事实类型、状态、时间、空间和脱敏来源摘要；禁止 `RawRelationInput.text`、私人描述、证据原文和原始消息。
- Agent 白名单：session/run/job 状态、队列、耗时、重试、错误码、工具名、资源 ID、服务端位置和二次脱敏诊断；禁止 prompt、消息、上下文、工具结果、token、密钥。
- 当前没有 contact/address 等字段，本任务不新增；未来字段接入时，电话/邮箱列表遮罩、详情需目标绑定 30 分钟访问会话。精确地址、学校/单位、健康和未成年人敏感字段永不返回。
- 原始错误仅可保留在服务端受限诊断存储；浏览器 API 只返回二次脱敏结果，审计不保存响应正文。

### SAP-F6：访问会话与读取审计

- 普通列表/运营元数据直接读但必须记录管理员、端点、筛选摘要、结果数、IP、request_id 和时间。
- 敏感详情先提交理由，创建绑定单个 `user` 或 `space` 的工作会话，有效 30 分钟；票据/会话不可跨目标复用，前端只存内存，详情响应 `Cache-Control: no-store`。
- 每次访问会话使用都写独立审计表；访问理由、资源类型/ID、授权范围和结果数永久保留；不写响应正文、密码、token、私密内容。
- 审计主体必须直接引用 `system_admin`，不把家庭 `users.id` 冒充管理员 actor。

### SAP-F7：审批唯一写例外

- 系统管理员可以审批空间管理员申请；approve 不强制理由，reject 必须非空理由；两者均需二次确认。
- 审批复用唯一 active `space_admin`、原管理员同意工单和单事务命令；终态不可改判；不触碰 `family_spaces.owner_id`。
- 禁止重置家庭 PIN、修改家庭档案、删除/恢复账号、数据权利 break-glass、争议决议、导出和附件下载。

## Out of scope

- 家庭用户注册和首个家庭账号创建。
- MFA、邮件/短信恢复、多系统管理员、多级角色和外部身份供应商。
- 电话、邮箱、地址、学校/单位、健康字段及家庭端档案编辑扩展。
- Memory、Session、AgentMessage、RAG 原文、关系证据原文和附件原文件浏览。
- 批量导出、全库快照、附件下载、家庭 PIN 重置、档案修改、删除/恢复和完整 break-glass 运维。
- Provider 管理、Agent runtime 控制面写操作和自动修复异常空间。

## Acceptance Criteria

- [ ] 家庭前端构建产物不含后台代码、路由、文案、API 路径或后台身份枚举；后台前端独立构建并运行在 5174/8081。
- [ ] 8000 家庭 listener 不注册 Admin API；8002 仅提供 `/admin-api` 管理员认证与后台 API；跨 listener token 互拒。
- [ ] 首次部署自动生成唯一 `admin` 账号和随机密码；凭据文件权限为 0600，首次改密后删除；固定默认密码不存在。
- [ ] 管理员用户名/密码变更和运维恢复会撤销全部管理员会话；refresh 轮换、短 access、独立 issuer/audience 生效。
- [ ] 后台能按 `space_admin → spaces` 展示成员/档案、关系/事实、运营积压、Agent 健康和异常队列，并支持分页搜索筛选与五秒监控轮询。
- [ ] 允许字段与禁止字段有精确 schema 测试；头像只通过鉴权缩略图；附件不返回路径或原文；Agent 错误经过二次脱敏。
- [ ] 敏感详情无访问会话、错目标、过期会话和跨目标复用均拒绝；理由、使用和结果永久审计，响应不缓存。
- [ ] approve/reject 空间管理员申请符合唯一写例外规则，其他高风险写操作不存在。
- [ ] 家庭端访问后台路径统一普通 404；家庭 OpenAPI/路由/静态资源不泄露后台存在；后台不反向引入家庭前端依赖。
- [ ] `backend/app/api/admin.py` 不再注册或被新后台复用；家庭用户仍无法访问任何管理员 API；既有家庭业务授权回归通过。
- [ ] 双前端 type-check、lint、test、build，后端定向/全量测试、Ruff、mypy、Compose 配置校验通过。

## Blocking open questions

无。上述决策均已由用户确认；如实现过程中发现技术事实与合同冲突，必须停止并回到父任务重新决策，不得静默扩大权限或兼容范围。
