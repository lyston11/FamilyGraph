# F：双 Agent 受控场景矩阵与浏览器链路验收

## 状态与目标

planning；仅规划，主会话内联。父任务 `09-17-dual-agent-latency-result-integrity`。目标：在零真实模型费用的隔离环境，证明修复后的时序、状态、安全与页面行为，消除“单元测试绿即真实链路成立”的验收空洞。

## 背景与范围

`d8d3668`已有 backend79项与sidecar42项定向回归通过，但5个审计反例证红。原集成报告以“未改前端”豁免浏览器验证，无工具/只读工具/多轮/压缩/排队/失败重试/取消失租的统一量化矩阵缺失。SDK假流只证明message_end发布边界，没有证明真实SSE/代理/渲染正常。

范围：复用现有tests与本地fake上游，把真实backend、sidecar、SSE、frontend串起来；兼容已有合成测试，不创建独立通用评测平台。不用生产库、真实用户或付费Provider。

## 需求与验收

| ID | 需求 | 验收结果 |
| --- | --- | --- |
| F-R1/AC1 | 助手完整场景矩阵 | 无工具、只读工具、纯工具轮、多轮、自动压缩、两run排队、单失败成功、耗尽、空最终回答、取消、失租各有源码版本/输入/时序/终态断言。 |
| F-R2/AC2 | 管家边界矩阵 | 成功+慢请求、响应头/body停顿、持续chunk、预发送耗尽、锁等待、接管、中断、混合恢复、四kind与合法空结果皆有请求数、保存/应用/费用及资源断言。 |
| F-R3/AC3 | 观测前后对照 | 同合成时序分别检查旧持久间隔与新源计时；注入延迟能归到正确阶段，错误分母不丢，不把mock生成速度称为真实模型提速。 |
| F-R4/AC4 | 真浏览器与传输链路 | 从提交/queued/工具/首正文到终态，覆盖断线Last-Event-ID恢复、刷新、取消、失权、跨空间切换；真实API/SSE而非route mock通过。 |
| F-R5/AC5 | 明确代理和时钟精度 | 独立测gateway chunk转发、公共SSE事件到达、渲染间隔；同机用monotonic，跨机给RTT/偏差区间，不能用SDK探针排除代理缓冲。 |
| F-R6/AC6 | 门禁与证据可复现 | 每格pass/fail/blocked及缺失原因可追溯，API smoke退出2不得算通过，所有必需格通过才可交G。 |

## 依赖与非目标

C/D/E集成后执行最终矩阵；规划可先做。发现业务缺陷退回所属任务，不能在验收任务无边界修改所有模块。与业务任务共享SQLite/端口/迁移时严格串行。

不实施delta、不调整档位或并发、不压测生产、不追加与本任务无关的UI重构。真实模型质量与线上服务版本由G验证。09-18 增量显示实施后，需对其变更范围补一轮F式验收（首段正文可见时间、权威最终替换、重连不重、失败不伪装成功），不能复用当前完整消息合同的通过证据。
