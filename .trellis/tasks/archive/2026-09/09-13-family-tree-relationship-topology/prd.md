# 家族树结构连线与布局修复

## Goal

让每位用户看到的家族树准确表达当前授权范围内人物之间的亲属结构：父母在上一代，兄弟姐妹同代，夫妻并排，子女连接自己的父母。个人视角保留可见范围、称谓和定位，不把所有人物都直接连到本人。

## Background

- 用户在 2026-09-13 提供 `/family-tree` 截图，指出所有连线从当前用户发出，妹妹应与本人平级；随后回复“执行”，同意建立任务并进入设计。

## Requirements

- **R1 直接关系连线（P1）**：连线对应当前用户有权看到的已确认亲属关系。妹妹、妹夫和孙辈不再仅因与本人有称谓关系而直接连到本人；同一真实关系只画一次，不能漏掉未被个人主路径选中的已授权直接关系。缺陷依据：`backend/app/services/personal_family_view.py:249` 固定摘要起点为本人，`frontend/src/composables/useFamilyTreeCanvas.ts:105` 将摘要原样画成连线。
- **R2 世代与家庭排列（P1）**：父母在子女上一代；有共同父母的兄弟姐妹同代；配偶同代并横向连接；子女排列在其父母下方。只有已确认兄弟姐妹关系而父母未知时，表达同代关系，不补造父母或婚姻。缺陷依据：`frontend/src/composables/useFamilyTreeCanvas.ts:126` 只按路径累计世代和 ID 排列，`frontend/src/components/canvas/MemberNode.vue:63` / `:81` 只有上入下出端口。
- **R3 个人视角**：节点称谓继续相对登录用户显示，保留本人强调与定位。切换查看者时，同一空间内双方共同获准的事实关系保持一致，可见范围仍分别授权。
- **R4 已有关系类型与交互**：保留生物、收养、继亲、监护、伴侣和直接兄弟姐妹等已有类型的区别；点击结构连线展示其实际两个端点之间的关系，个人关系路径说明仍可访问。保留节点导航、树状/自由画布、缩放和刷新。
- **R5 授权与一致性**：不新增可见人员、不扩大关系读取权限、不暴露隐藏端点；撤权、关系失效或桥接授权到期后不得继续显示仅依赖该授权的人员与连线，即使尚未收到后台状态更新事件。称谓、人员资料和统计等既有消费者保持兼容。
- **R6 复杂结构与兼容**：同一人只显示一个人物节点；多父母、再婚、孤立节点不能导致崩溃、无限布局或虚构事实。世代约束不一致时保留真实关系，提示并回退自由画布。与已有推测层保持明确区分，本任务不新增推测能力。

## Acceptance Criteria

- [ ] **AC1 → R1/R2**：本人和妹妹有共同父母时，两人同代，分别连接已有父母；不存在仅用于表示“我的妹妹”的本人→妹妹结构边。
- [ ] **AC2 → R1/R2**：配偶在同代横向连接；子女连接自己的父母，孙辈连接其父母，不出现本人跨代直连所有孙辈。
- [ ] **AC3 → R1/R4**：已授权的另一位父母、非本人配偶等直接关系即使不在个人主路径中，仍准确显示且无重复；未确认的婚姻、父母和关系不被补造。
- [ ] **AC4 → R3**：不同账号在同一空间查看双方共同获准的关系时，直接事实端点一致；称谓、本人标识、定位和可见范围随账号正确变化。
- [ ] **AC5 → R4/R6**：父母未知的已确认兄弟姐妹、多父母、再婚和孤立节点能稳定显示；世代冲突时有明确提示和可用画布；结构连线说明与其两个端点一致，个人称谓说明仍正确。
- [ ] **AC6 → R5**：隐藏节点、撤权、事实撤回/修改、失效跨空间授权与缓存复用场景均不泄露或保留不再有效的关系；仅时间跨过桥接有效期、未写状态或发事件时也立即失效；原有个人资料和统计接口行为不退化。
- [ ] **AC7 → R6**：推测关系不能混入已确认结构边，授权桥接不能被画成亲子或配偶事实；现有推测层并行任务的改动在串行集成时被保留。
- [ ] **AC8 → R1–R6**：针对截图所示兄弟姐妹、配偶、子女、孙辈场景完成真实页面检查；受影响后端与前端自动检查通过，未运行或受环境阻塞的检查有明确记录。

## Out of Scope

- 新增亲属推测、自动补全、称谓规则、跨空间发现、成员管理或管理员开关功能。
- 修改已确认事实、用户资料、旧图接口及其位置数据；扩大当前用户的授权范围。
- 更换整套视觉主题、增加新布局模式或承诺任意复杂族谱完全没有线条交叉。
