# 技术设计与实现结果

## 边界与根因

`familyTreeLayout.ts` 原有逐行从 0 排布和重心排序没有计算后代宽度；sibling 与配偶使用同一 sym 类型，导致兄弟姐妹和他们的配偶合成横排大块。`FamilyTreeView.vue` 在算法之后保留旧 x 并逐节点向右避让，会覆盖新分支坐标。因此必要改动包括布局纯函数和页面的树模式坐标消费，以及两者的回归测试。后端、API、样式、关系事实不变。

## 算法

1. 保留连通分量、世代约束、viewer 行对齐和矛盾返回 null。
2. 保留边类型；配偶/伴侣先并查集分块，共同父母再合成几何组，块内保留配偶组顺序。兄弟姐妹仅约束同代。
3. 每个子代块选择唯一父代几何区间：不同亲子连接数量最多者优先，同数按稳定最小成员 id。仅用于几何，所有真实关系边保留；跨支系婚姻不复制人物。
4. 自底向上宽度取本块宽度和后代总宽度加间隔的最大值；自顶向下分配区间，父母和后代区域居中。整个分支保留预分配宽度，不做会拆散分支的逐节点压缩。
5. 同一层各子树区间互斥，最小块间隔 max(24, colSpacing-cardWidth)；无需额外向右修正。
6. 页面树模式直接消费算法坐标，拓扑变化允许重新布局；layoutIdentity 排除称谓/进度，文本更新不重排。自由画布拖动和视口行为保留。

## 兼容性与限制

输入输出类型不变；confirmed/inferred 隔离与回退逻辑保持。跨支系婚姻无法保证所有父母同时居中或所有连线无交叉，优先唯一人物、真实边、不重叠和确定性。未做完整连线路由重构。

## 验证

纯函数及页面相关 61 测试通过；全部前端 743 测试、lint、type-check、build 通过。真实 Vue Flow + MemberNode 的 11 人三代示例浏览器核验完成，截图 `.playwright-mcp/fg-layout-verified.png`（主检出，本地证据，不提交）。截图中的用户 30 人真实载荷未复测。
