# 前端高级星空底、透明磨砂卡片与圆形底部操作重构 PRD

## 1. 目标与背景

当前前端页面设计偏传统偏灰暗，缺乏现代高级感与视觉冲击力。本次重构聚焦于将普通家庭用户端从老旧风格全面升级为具有**高级感、科技与温情并存、具有画布感星空底与通透磨砂玻璃（Glassmorphism）**的视觉体验。

核心场景动线：
```text
登录系统
  └── 默认进入：家庭空间大卡片（我的家庭）
        ├── 视觉：高级透明磨砂玻璃卡片悬浮在星空底上，中心聚焦高光
        ├── 操作：主要功能操作统一收敛为页面底部的【圆形小按钮浮动操作栏】
        └── 退出大卡片 → 家族空间树（PersonalFamilyView）
              ├── 视觉：深邃深远画布感的静态星空画布
              ├── 树状形态：家族树成员就像星空中一颗颗闪耀的星宿节点（圆形微光星体节点）
              ├── 节点连线：通透细微光轨道连线
              └── 底部操作：居中浮动圆形小按钮群（回到自己、缩放、布局切换、退出/返回家庭卡）
```

## 2. 关键设计与需求原则

### 2.1 画布感星空底（Cosmic Canvas Background）
- **深邃与画布感**：全局使用深邃星空质感，背景包含多层微光星尘、星系漫射光（Nebula Glow）以及疏密有致的静态星点。
- **纯 CSS 高性能实现**：遵循架构规范（不引入重度 Canvas 粒子或漂移耗电脚本，保持静态性能），利用多层 `radial-gradient` 与混合模式，实现极具纵深感的星空画布。
- **全站统一浸润**：`AppShell`、`HouseholdCardView`、`FamilyTreeView`、`PersonProfileView` 等页面贯穿同一星空底座。

### 2.2 高级透明磨砂卡片（Glassmorphism & Depth）
- **磨砂透明质感**：背景采用半透明高透光材质，配合 `backdrop-filter: blur(...)`，透出背后星空的微光斑驳。
- **珠宝级高光边框**：使用精致的半透明发光内描边（`border: 1px solid rgba(..., 0.15~0.25)`），在边缘产生晶莹剔透的高光线。
- **多层微光阴影**：卡片在悬停（Hover）与聚焦（Focus）时，具备环境色柔光散射（Glow Diffusion），卡片呈现悬浮层次。

### 2.3 页面底部圆形小按钮（Floating Circular Action Dock）
- **操作交互重构**：将传统突兀的长方形按钮条、复杂按钮组统一升级为**位于页面底部或容器底部的圆形小按钮（Circular Floating Icon Buttons / FAB Dock）**。
- **形态特征**：
  - 40px~48px 圆形，毛玻璃半透明材质，精致图标居中；
  - 悬浮在页面底部（底栏或卡片底部），具备精致悬浮阴影与 Hover 上浮光晕；
  - 支持 Tooltip 提示文字，点击反馈轻盈灵动；
  - 移动端适配：保证触控热区至少 44px。

### 2.4 家庭空间大卡片（Household Card）
- **登录默认落地**：登录后首先呈现家庭空间大卡片。
- **通透大卡片**：左侧本人资料、右侧家庭成员，通透悬浮于星空底之上。
- **退出交互**：左上角/底部提供醒目的“退出至家族树”圆形/流线操作，丝滑转场至家族空间树。

### 2.5 家族空间树：一颗颗星宿节点（Constellation Nodes）
- **星宿节点形态**：家族树中的每个成员节点设计成如同**星宿/星体（Orb / Celestial Node）**一样的精致圆形或微圆角流光水晶体。
- **层级与光效**：本人节点带有独特的引力光环（Pulsing Accent Halo），直系亲属具有微光光晕，非直系亲属节点清透微亮。
- **连线与轨道**：关系连线如星轨般细腻、微带荧光，点击连线依然弹出通透磨砂的关系说明面板。

### 2.6 系统后台前端同套视觉（system-admin-frontend，2026-09-05 范围扩展）
- **同套星空玻璃语言**：`system-admin-frontend` 应用同一「星空底 + 磨砂玻璃」视觉（登录页、壳层导航、概览指标卡、通用卡片/表格面板）。
- **隔离红线**：后台前端保持零家庭依赖（不 import 家庭端 store/组件/API/token），视觉改造只落在其自有 `--ag-*` token 体系（`src/styles/main.css`）与组件样式，颜色一律走 `--ag-*` 变量。
- **克制原则**：后台以信息密度与可读性优先，玻璃通透度低于家庭端；表格数据区保持高对比易读，不引入动效脚本。

## 3. 验收标准（Acceptance Criteria）

1. **视觉质感**：全站主界面展示深邃星空底与通透毛玻璃卡片质感，字体清晰，对比度满足 WCAG AA 可读性标准。
2. **操作体验**：家庭大卡片与家族树的核心操作通过底部精致的圆形小按钮提供，交互轻巧明确。
3. **流程一致**：登录后进入家庭空间大卡片，点击退出直达家族空间树，家族树各节点呈现为一颗颗星体般的节点；家族树底部 Dock 提供「返回家庭卡」反向入口。
4. **测试与性能保障**：
   - 现有 Vitest 单元测试与 18 项移动端适配测试全部保持通过；
   - TypeScript 类型检查无报错；
   - 生产构建（`npm run build`）成功；
   - system-admin-frontend `npm run type-check` 与 `npm run build` 零缺陷（该应用当前无单元测试套件）。
