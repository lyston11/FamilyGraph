## 3. 权限与歧义反例

| ID | 情形 | 期望 |
|---|---|---|
| N01 | A 查“春节/北京”，B private X1 在原始文本排名靠前 | X1 不返回；合法 M1 在扫描预算内可补足 |
| N02 | A 查 H2 X2；修改客户端 space_id/来源 locator | 不扩大 membership，不回 X2 |
| N03 | X3 三种失效状态重复 index/rebuild/repair | 不复活，结果无 X3 |
| N04 | X4 pending、X5 unverified | 不进入任何 AgentContext；legacy 管理响应不反显摘要/原文 |
| N05 | X6 使用云 Provider 与本地 Provider 对照 | 云路径按当前本地要求拒绝/排除，不以提高召回为由外发 |
| N06 | 空会话问“他呢？”；其他 session 提过外公 | 不将别的 session 人物写入 plan，不伪称已消解 |
| N07 | 同会话前文并列外公/舅舅，问“他呢？” | 不猜实体；降级原因可观测，不能把检索结果当成指代证明 |
| N08 | FTS 运算符/引号/括号/分隔符、仅标点、空白 | 以数据处理或明确拒绝，无查询语义注入/500 |
| N09 | 一字高频词与超长问题 | 有限扫描/稳定截选或明确要求缩小问题，不无界 LIKE |
| N10 | 原共享来源保存为 private 后撤销/失权 | 副本每读取面依赖仍有效执行，不洗成 manual |
| N11 | 新 index_version staging、旧版与新版 chunks 同时在 FTS | 新检索只活动版本；历史引用精确原块，未切换版本不泄出 |
| N12 | RAG-only/Memory off | 能在授权范围检索已有合法投影，不能保存新候选 |

反例没有“允许泄露一点”的通过比例；所有被禁止的来源均不得返回。数据规模扩展只增加合成干扰，不更改期望来源或权限。

## 4. 扩展与语义能力集

为 E 冻结独立集，至少覆盖下列组，每组含多个未在核心词表专门调优的改写与干扰：
- 不共享连续字串的同义表达，如“新春团圆饭的城市”；
- 多条件、人物昵称和否定/更正；
- 长段跨句事实与时间版本混淆；
- 无资料/问题超出来源的应答；
- 需要第二步检索而一次预取不足的明确实体链。

由人工或预先编写的 fixture 标注 relevant source IDs 与允许答案范围，不能用待测模型自评为唯一真值。核心集用于防回归，扩展集报告 Recall@5/MRR/错误命中，不把词法一期的指标承诺扩大成通用语义达标。所有选型增益、延迟与成本目标在实验前冻结，结果不佳允许延期。
