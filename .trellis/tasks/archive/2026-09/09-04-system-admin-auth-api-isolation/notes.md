# 子任务 1 决策与实现笔记

- 用户端与管理员端不是同一产品入口；8000/8002 是不同 API 面。
- 系统管理员不使用家庭用户的名字+PIN，而使用用户名+强密码。
- 默认账号只固定用户名 `admin`，不固定密码；随机密码通过 0600 文件一次性交付。
- 不做旧 system_admin PIN 迁移，因为当前目标是新设计，不保留兼容窗口；家庭用户 PIN 完全不动。
- 首版单管理员、无 MFA；密码找回只能通过受限运维恢复。
- 独立 JWT 签发域的意义是：端口隔离之外，复制 token 到另一 listener 也必须失败。
- 8002 只在内部 admin 网络监听；家庭 API 不能通过“隐藏前缀”间接访问后台。
- 家庭响应不再暴露 system_admin/platform_operator 枚举，避免用户端从 API 合同得知后台身份模型。
