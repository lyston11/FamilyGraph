# 管家自动修复称谓：词典补全+长幼消歧+自愈闭环

> 历史范围说明（2026-09-13 补记）：下文 R3 的自动写 space 词条是早期方案，最终 [design.md](design.md) 与 ade0a2b/e882789 实际采用词包、长幼消歧和长链泛化，没有自动词典写入。本 PRD 的历史验收不能作为该能力已实现的证明。后续称谓建议/模型优化由 [称谓闭环总任务](../../../09-13-steward-kinship-capability-closure/prd.md) 接管；原任务完成状态和实现历史不改写。

## Goal

家族树上不允许再出现「你的父亲的女儿」「你的儿子的儿子」这类机器人式称谓。三管齐下：

1. **补全 zh-CN 内置词典**：常用亲属概念码（≤3 跳）一次性补齐，确定性解析命中人话称谓；
2. **长幼消歧**：兄弟/姐妹类称谓用出生日期选 哥哥/弟弟/姐姐/妹妹（未知回退泛化词）；
3. **管家自愈闭环**：管家作业巡检本空间仍存在的结构性回退称谓（词典未覆盖的罕见长链），
   自动把正确词条落到 space 层并触发视图重算——**用户零操作，树自己变对**。

## 背景（根因证据）

- 称谓解析四级词典（personal > space > locale > system）未命中时回退结构描述
  （`services/terms.py::resolve_term_or_structural`，SOURCE_LEVEL_STRUCTURAL）。
- 内置 zh-CN 种子仅 ~40 条（`models/term_registry.py::BUILTIN_ZH_CN_TERMS`）：
  `Sf/妻子、Dm/儿子、Dm-Sf/儿媳` 等命中码正常显示；`Um-Df`（父亲的女儿→妹妹）、
  `Dm-Dm`（儿子的儿子→孙子）、`Dm-Df`（孙女）、`Um-Df-Sm`（妹夫）等未收录，
  全部回退成路径描述（2026-09-13 用户截图实证）。
- 概念码合同只含性别不含长幼（`relationship_resolver._step_token`），长幼需由
  出生数据（`users.birth`，JSON 列）在解析时消歧。
- 用户诉求：管家 agent 直接处理并修改这类不合理称谓，用户不手工干预。

## Requirements

- **R1 词典补全**：zh-CN 内置包覆盖 ≤3 跳常用亲属码（直系、旁系、姻亲：祖辈、
  孙辈、兄弟姐妹、侄甥、堂表、姑舅姨叔伯、翁婿婆媳、姐夫妹夫大伯小叔等），
  同步更新 system 兜底包；种子写入与 `seed_builtin_packs` 幂等机制兼容
  （迁移 0012 同款清单共享来源）。
- **R2 长幼消歧**：直接兄弟姐妹及其配偶类称谓（哥/弟/姐/妹、嫂子/弟妹/姐夫/妹夫）
  依据两端出生日期确定长幼；出生信息缺失或对 viewer 不可见时回退泛化词
  （兄弟/姐妹等）。消歧是确定性规则，不引入模型调用；personal/space 层已有
  自定义词条的用户不受影响（优先级更高，照旧生效）。
- **R3 管家自愈闭环**：管家核心作业新增巡检步骤——检测本空间 PFV 中
  `term_source_level=structural` 的边；对词典仍未覆盖的概念码，按确定性
  生成规则（长链泛化称谓，如最近的已命名祖先词 + 链式后缀）落 **space 层词条**
  （写入带审计、revision 链）；落词后重算本空间视图，树自动更新。
  - space 层词条写入需有开关治理：平台 env + 空间级开关，默认关、生效语义 AND
    （与辅助开关同款 fail-closed）；面板提示机制与
    09-13-steward-assist-platform-switch-admin 对齐。
  - 用户手动个人纠正（personal 层）永远优先，管家落词绝不覆盖用户已有词条。
- **R4 确定性红线**：全程零模型调用（v1 不做 LLM 造词）；相同 (码, 数据) 永远
  产出相同称谓；词典/消歧/落词全部可单测。
- **R5 一致性**：词典种子变更与 `TermEntry` 新列走 Alembic 迁移；PFV
  `COMPUTATION_VERSION` 升版触发重算；被管家落词影响的空间视图在作业内重算。

## Acceptance Criteria

- [ ] 截图黄金用例回归：viewer 王德海（1953）空间中——父亲之女（1962）→「妹妹」，
  儿子之子→「孙子」，儿子之女→「孙女」，父亲之女的丈夫→「妹夫」（随长幼消歧），
  妻子/儿子/儿媳等既有正确显示不回归。
- [ ] ≤3 跳常用码在 zh-CN 包内无缺漏（枚举测试：对码表全集逐码断言词条存在）。
- [ ] 长幼消歧：年龄差可判 → 哥哥/弟弟/姐姐/妹妹正确；缺失/不可见 → 泛化词；
  personal/space 词条优先于消歧结果。
- [ ] 管家作业后：结构性回退边数量下降至词典/泛化规则可覆盖范围；落词条目可在
  审计中溯源（origin=steward）；开关关闭时不落词、树行为与现状一致。
- [ ] 用户 personal 纠正优先不被覆盖（既有 KI-4 行为不回归）。
- [ ] 迁移在隔离库 `alembic upgrade head` 通过；backend 全量门禁
  （ruff/mypy/pytest）通过；前端无改动（或仅类型同步），门禁按实际改动范围跑。
- [ ] 四级词典/解析相关既有测试（test_terms、test_relationship_resolver、
  PFV 相关）全绿。

## 非目标

- LLM 生成称谓文本（确定性规则覆盖不了的极长链保留结构描述，留待后续评估）。
- 伯/叔、堂表分长幼（需父辈长幼链消歧，v1 用泛化词：叔伯/堂兄弟等）。
- 推测层（缺关系自动补全）——独立任务 09-13-steward-inferred-tree-layer，本任务完成后进行。
