# 管家称谓建议与模型优化闭环

## Goal

让管家实际生产个人称谓建议，并在既有关系依据内自动应用确定性或模型改善；用户可选择保留或恢复，无需逐条批准称谓。

父任务：[称谓能力闭环](../09-13-steward-kinship-capability-closure/prd.md)。本子任务负责父 R-03/04/05/07 和 R-02 的自动投影刷新，当前仅规划。

## Dependencies

必须先完成并串行集成 [A](../09-13-steward-kinship-presentation/prd.md)，取得其 presentation/来源/有效状态合同。以已完成平台开关治理为基线；与 memory 的配置/迁移工作串行。A/B 共用 Terms/PFV/Suggestions/前端类型，不并行写。E 的 MR-23/MR-26 研究不是本任务运行前置，不接入其未完成的全量行为重建。

## Requirements

- B-R1（P1）：在真实 Steward core 中发现确定性改善、本人明确用词以及合格模型产物，生产绑定 viewer/target 的 term_preference；同依据幂等，无改善无新建议。依据：steward_suggestions.py:176,270,758。
- B-R2（P1）：自动显示结果持久为可失效投影，PFV/通知/档案共同消费。自动应用不调用 set_personal_term/record_usage/关系提案；个人和 active 空间词条优先。
- B-R3（P1）：新增专用 terminology prompt/schema/validator。每次调用只读一个 viewer 的获准路径与本人相关反馈，支持自然同义词和合法组合叫法；方向、继养监护、未知性别/长幼不能被改义。依据：steward_assist.py:63,104,321；intake_extractor.py:68,255 的码不能区分长幼。
- B-R4（P1）：生产注册、预留、网络、写回、恢复全部接入现有 assist；每个阶段重验 viewer/路径/词条/反馈版本。失败保留既有且仍有效的称谓，无有效自动结果时回退确定性基线；不得只测试手工插入产物。
- B-R5（P1）：可选保留复用本人词条；恢复原叫法即时生效并记本人的语义拒绝，防止同词同语义反复应用；忽略建议与恢复叫法区分。自动行为不伪造人类使用或影响别人的推荐冷却。
- B-R6（P1）：完整接入环境/平台/空间/Provider 开关、预算、健康与统计，默认关闭模型增强；配置可达，后台能说明实际不可用原因。模型关闭时自动确定性称谓保留。
- B-R7：不逐条发称谓待办；在已有 KinshipTermPanel 展示可选建议和来源。恢复/保留后刷新通知与家族树相关缓存；旧称谓通知安全兼容。

## Out of scope

不增加私人聊天/RAG/跨空间发现/新 Agent runtime，不自动确认关系，不替代 TermRegistry，不承诺任意新造方言词可验证，不扩大后台人员读取家庭正文的权限。

## Decisions

模型允许生成可核验的自然称谓；不能核验的输出放弃而非推给用户审批。自主结果作用于当前账号和空间，主动保留后的个人词条继续按现有概念跨空间生效。未使用真实模型不等于缺少生产接线，但交付不能声称真实模型质量已测。
