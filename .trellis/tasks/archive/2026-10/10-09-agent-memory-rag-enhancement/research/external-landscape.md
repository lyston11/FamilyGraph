# 外部对照：记忆与检索的已知结论

只记录**已核实**的结论。未核实的数字标为「待本地验证」，不作为设计依据。

## 1. 评测维度（可直接借用）

**LongMemEval**（ICLR 2025，arXiv:2410.10813）定义了长时记忆的五个核心能力：
信息提取、多会话推理、时序推理、**知识更新**、弃答（abstention）；500 道题嵌在长会话历史中。
论文报告商用助手与长上下文模型在持续交互下准确率下降约 30%（数量级结论，非本环境实测）。

→ 直接映射为本任务的评估维度：G1 对应「知识更新」，G4 对应「多会话推理 / 时序推理」，
弃答对应「检索不到时不要编」。

## 2. 系统对照（能力面，非性能结论）

| 系统 | 提取 | 管理操作 | 存储 | 检索 |
|---|---|---|---|---|
| MemGPT | 直接归档 | 整合 / 变换 / 更新 | 分层 + 向量 | 词法 + 向量 |
| MemoryBank | 直接归档 | 整合 / 更新 / 过滤 | 扁平 + 向量 | 向量 |
| A-MEM | 摘要式提取 | 连接 / 更新 | 扁平 + 向量 | 向量 |
| Zep / Graphiti | 事实抽取 | **时序失效** | 时序知识图谱 | 图 + 向量 |

来源：ACL Findings 2026 记忆演化综述；`Memory in the LLM Era`（arXiv:2604.01707）能力对照表。

**Zep / Graphiti**（arXiv:2501.13956）的要点不是「用图」，而是**给事实加时间有效区间**
（valid/invalid），使「新事实取代旧事实」成为一等语义，并在 DMR 上超过 MemGPT。

→ 对本项目最相关的结论：**G1 的解法是时间有效区间 + 取代指针，不需要引入知识图谱**。
家族图谱本身已是结构化事实源，记忆层要解决的是「记忆行之间的取代关系」。

## 3. 检索侧

- 词法（BM25 / PGroonga）与向量互补：本项目已实测 PGroonga 在中文上 10/10 精确，
  `pg_trgm` 因 CJK 相似度低于阈值被排除（见 `10-04-lexical-search-migration` 证据）。
- 融合顺序：授权过滤 → 两路候选 → union → rerank → revision/citation 复核
  （已在 `10-03-pgvector-rag/design.md` 固定）。
- rerank 的两种形态：**确定性特征重排**（可复现、零外部依赖、可测）与
  **cross-encoder**（质量更高但引入服务与延迟）。本项目尚无 golden set，
  因此先做前者，用数据决定是否值得引入后者。

## 4. 待本地验证（不得作为设计依据）

- contextual retrieval（chunk 前加文档级上下文）在中文家族文本上的召回增益；
- cross-encoder 在中文亲属 / 家族语料上的排序增益与延迟代价；
- 中文 embedding 模型在本项目语料上的召回率；
- 分层上下文预算相对贪心填满的实际收益。
