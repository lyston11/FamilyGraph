# C6：Embedding 服务实测（ARM64 生产服务器）

日期：2026-10-07
环境：`lyston` 服务器（`aarch64`，4 核，23.4 GiB 内存）
镜像：`fg-embedding:probe`（878 MB，两阶段构建）
模型：`BAAI/bge-small-zh-v1.5`（4 层 / 512 维 / 512 token 上限 / CLS 池化）

## 结论

**embedding 服务在硬限制下稳定运行，且不干扰同机的生产/开发服务。**

| 指标 | 实测 | 预算 | 占用 |
|---|---|---|---|
| 空载内存 | **203 MiB** | 1 GiB | 20% |
| 峰值内存（24 并发） | **241 MiB** | 1 GiB | 24% |
| 峰值内存（4×满长文本最坏情况） | **222 MiB** | 1 GiB | 22% |
| 模型加载耗时 | **0.22 s** | — | — |
| 单条查询延迟 | **71 ms** | — | — |
| 批量 4 条文档 | **32 ms** | — | — |
| 单批 4 条满长（512 token） | **1873 ms** | — | — |
| OOM | **否**（`OOMKilled=false`） | — | — |

## 并发上界：直接证据

`max_observed_active` 是闸门的自我记录，**任何时刻都不得大于配置的 1**。

| 场景 | 并发 | `max_observed_active` | 结果 |
|---|---|---|---|
| 24 并发请求 | 24 | **1** | 全部成功，0 拒绝 |
| 8 并发持续负载（160 次请求） | 8 | **1** | 0 拒绝，7 个在队列等待 |

24 个请求总耗时 13.4 s，p50 432 ms、p95 461 ms——说明它们被**串行化**执行，
而不是并发。这正是设计目标。

## 不干扰同机服务：决定性证据

持续满载期间（embedding CPU 稳定 **100%**、8 并发、7 个排队）测量同机 dev API：

| 时点 | dev API 健康端点延迟 | 系统 load |
|---|---|---|
| 基线（无 embedding 负载） | 1.66 / 1.82 / 1.80 / 1.81 / 1.81 ms | 0.17 |
| embedding 满载期间 | 2.05 / 1.88 / 1.91 / 1.99 / 1.71 / **3.74** / 1.79 / 2.12 / 2.14 / 2.07 / 1.83 / 1.87 ms | 0.36 → 0.75 |

**延迟与基线无实质差异。** `cpus=1.0` 硬限制使 embedding 最多占用 1 核，
剩余 3 核留给生产与开发。load 从 0.17 升到 0.75（单核满载的预期值），
未接近 4 核饱和。

## 语义正确性

| 检查 | 结果 |
|---|---|
| 池化方式 | `cls_token=True, mean_tokens=False`（与模型配置一致，已校验） |
| 维度 | 512（与 `EMBEDDING_DIMENSION` 一致，不一致会 fail-loud） |
| 同义相近 | 叔叔 ~ 爸爸的弟弟 = **0.623** |
| 无关区分 | 叔叔 ~ 今天天气真好 = **0.299** |
| 截断报告 | 1200 字输入 → `tokens=512, truncated=True`（不静默截断） |

语义检查证明这不是「返回随机向量」的实现——同义关系的相似度显著高于无关文本。

## 截断报告（修掉的自己的缺陷）

初版 `server.py` 写了 `tokens = [min(len(t.split()), 0) ...]`——**恒为 0**，
即截断报告是假的。若保留，一个被静默截断的段落会看起来完整，检索会漏掉后半段
且无人发现。已改为从 `attention_mask` 求真实 token 数。

## 构建期发现的两个真实依赖问题

1. `optimum==1.21.2` 要求 `transformers<4.43.0`，与 `transformers==4.44.2` 冲突
   → **ResolutionImpossible**。而导出脚本根本不用 optimum（直接调
   `torch.onnx.export`），是**未使用**的依赖。
2. `torch.onnx.export` 需要 `onnx` 包做 protobuf 序列化，缺失时报
   `Module onnx is not installed!`。

两者都只在**真实构建**时暴露，静态检查看不到。
